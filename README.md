# ChurnGuard – Customer Churn Prediction System

An end-to-end machine learning project that predicts which telecom customers are likely to leave (churn), shows the churn probability, and presents insights in an interactive Streamlit dashboard.

## Status
🚧 Work in progress – currently in project setup.

## Planned Features
- Explore and understand the IBM Telco Customer Churn dataset
- Clean the data and build a preprocessing pipeline
- Train and compare multiple ML models
- Predict churn probability for a single customer
- Interactive dashboard built with Streamlit

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Streamlit

## Setup
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
